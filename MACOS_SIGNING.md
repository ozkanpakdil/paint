### macOS Installation and Signing Guide (Rust GTK App)

This guide explains how to build, package, and sign the **Rust GTK** version of the Paint application for macOS.

#### Prerequisites

1.  **Rust Toolchain**: Install via [rustup.rs](https://rustup.rs).
2.  **System Dependencies**:
    ```bash
    brew install pkg-config gtk4 cairo libadwaita
    ```
3.  **cargo-packager**: Install the packaging tool:
    ```bash
    cargo install cargo-packager --locked
    ```
4.  **Apple Developer Account**: A valid membership.
5.  **Certificate**: A "Developer ID Application" certificate in your Keychain.
    - To find your identity string, run:
      ```bash
      security find-identity -v -p codesigning
      ```
    - Look for the line starting with `Developer ID Application: Your Name (TEAMID)`. Use either the full string in quotes or the 10-character alphanumeric ID (e.g., `TA5X5C9T57`).
6.  **App-Specific Password**: For notarization. This is **not** your main Apple ID password. You must generate it at [appleid.apple.com](https://appleid.apple.com):
    - Sign in to [appleid.apple.com](https://appleid.apple.com).
    - Go to **App-Specific Passwords** section.
    - Click **Generate an app-specific password** or the **+** button.
    - Give it a label (e.g., "RustPaint Notarization").
    - Copy the generated password (usually in the format `xxxx-xxxx-xxxx-xxxx`).

---

#### 1. Automated Build, Signing, and Release

A helper script `build_macos.sh` is provided in the `rust/` directory to automate the build, signing, notarization, and GitHub release process.

```bash
cd rust
# To just build and package without signing:
./build_macos.sh

# To build, package, sign, and notarize:
# (SIGNING_IDENTITY is now auto-detected if not provided)
export APPLE_ID="mail@mail.com"
export APPLE_PASSWORD="xxxx-xxxx-...."
export TEAM_ID="TEAMID"
./build_macos.sh --sign

# To build, sign, notarize, AND create a GitHub Release:
# (Requires GitHub CLI 'gh' to be installed and authenticated)
./build_macos.sh --sign --release
```

---

#### 2. Manual Steps (Optional)

You can still perform the steps manually if needed.

#### 2.1 Signing the App Bundle

`cargo-packager` handles basic packaging, but for full macOS distribution, you should sign the `.app` bundle before creating the DMG, or sign the DMG itself.

To sign manually:
```bash
cd rust
# Define your identity
SIGNING_IDENTITY="Developer ID Application: Your Name (TEAMID)"

# Sign the .app bundle
codesign --deep --force --options runtime --timestamp --entitlements entitlements.plist --sign "$SIGNING_IDENTITY" "target/release/RustPaint.app"
```

---

#### 2.2 Notarization

Apple requires apps distributed outside the Mac App Store to be notarized.

1.  **Submit for notarization**:
    ```bash
    cd rust
    xcrun notarytool submit target/release/rw.RustPaint_0.1.0_aarch64.dmg \
      --apple-id "your-apple-id@email.com" \
      --password "your-app-specific-password" \
      --team-id "YOUR_TEAM_ID" \
      --wait
    ```

2.  **Staple the ticket**:
    ```bash
    cd rust
    xcrun stapler staple target/release/rw.RustPaint_0.1.0_aarch64.dmg
    ```

---

#### 2.3 Installation on Mac Mini

1.  Open the generated `.dmg` file.
2.  Drag **RustPaint** to your **Applications** folder.

#### Troubleshooting

-   **Finding your Signing Identity**:
    `security find-identity -v -p codesigning`
-   **Entitlements**:
    If the app fails to start due to Hardened Runtime, you may need to provide an `entitlements.plist`.
-   **Verification**:
    To check if your app is correctly signed and notarized:
    ```bash
    codesign -dv --verbose=4 path/to/RustPaint.app
    spctl --assess --verbose --type execute path/to/RustPaint.app
    ```
    If it's notarized correctly, `spctl` should say `accepted`.

-   **"Resource busy" Error during DMG creation**:
    If `cargo packager` fails with `hdiutil: couldn't unmount ... - Resource busy`, it means a previous build attempt left the DMG volume mounted. The `build_macos.sh` script now tries to unmount it automatically, but if it still fails, you can manually unmount it using:
    ```bash
    hdiutil detach /Volumes/RustPaint -force
    ```

-   **Gatekeeper "Damaged" Error**:
    If you download the app from the internet (e.g., GitHub) and see an error saying it is "damaged", it is usually because:
    1.  The app was NOT notarized by the developer.
    2.  The app was notarized, but the notarization ticket was NOT stapled to the DMG (run `xcrun stapler staple your.dmg`).
    3.  You are trying to run the `.app` directly without it being inside a signed/notarized `.dmg`.

    Always distribute the app via the signed and notarized **.dmg** file generated by `build_macos.sh --sign`.
